# Neko Product Principle

## One Core Principle

**Real time creates virtual responsibility.**

Neko is not built around rewards. It is built around the feeling that a small life keeps changing while the user is away, and that the user is responsible for what happens next.

```
Real time passes
→ the pet changes without the app being open
→ the user sees a specific time when care is needed
→ neglect has a visible public consequence
→ the user returns at the right time
```

## Non-Negotiable Conditions

1. **The pet must get worse, not merely stop improving.**
   If absence only means no reward, the user can ignore it. If absence creates loss, the user feels responsible.

2. **The user must know when to return.**
   Vague anxiety makes people avoid the product. A concrete countdown creates action.

3. **Neglect must be publicly visible.**
   Private failure is easy to tolerate. A low public health score is harder to ignore.

## Neko Formula

```
Real time passes
→ hunger, cleanliness, and mood decay
→ countdowns show when the next problem will happen
→ leaderboard health score exposes the result
→ the user comes back before the visible loss
```

## Feature Gate

Every new feature must answer yes to this question:

> Does this make the user more clearly feel that time is passing, I am responsible, and others can see the result?

If yes, consider it. If no, leave it out.
